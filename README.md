# Noir Chauffeur — luxury ride booking demo

Clickable front-end prototype built for a private chauffeur service:
booking wizard, checkout with card / Apple Pay / Google Pay, live ride tracking,
driver ratings & reviews, and an operations admin panel.

Static demo — no backend, no real payments. State is kept in localStorage so the
flow can be walked end to end.

Pages: `index.html` · `book.html` · `track.html` · `rate.html` · `admin.html`
